# 🛍️ ShopSmart — Modern E-Commerce Experience

ShopSmart is a sleek, responsive e-commerce web application built with React.
It delivers a smooth, immersive shopping experience with a modern dark-themed UI.

---

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/shopsmart.git
cd shopsmart
```

---

### 2. Install dependencies

```bash
npm install
```

---

### 3. Run the development server

```bash
npm run dev
```

---

### 4. Open in browser

```
http://localhost:5173
```

---

## 💾 State Management

* **CartContext** → Handles cart items & quantity logic
* **WishlistContext** → Manages saved products
* **DataContext** → Fetches and provides product data

All states are persisted using **localStorage**.

---

## 🔔 Notifications

User actions like:

* Adding to cart
* Removing items
* Wishlist updates

…are communicated via styled toast notifications.
